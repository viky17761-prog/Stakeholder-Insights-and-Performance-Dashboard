# Stakeholder-Insights-and-Performance-Dashboard

📊 Project Overview
An interactive Tableau dashboard designed to provide a comprehensive view of stakeholder, insurer, and policy performance. The dashboard helps analyse premium trends, profitability, insurer value creation, stakeholder shareholding, and asset distribution for data-driven decision-making.
🎯 Key Insights & Analysis
Compared Value Created across different insurers
Analysed premium collection trends over time
Visualized stakeholder shareholding patterns
Examined the relationship between Cost Ratio and Profitability
Analysed profitability by city and policy tenure
Visualized Assets Under Management (AUM) distribution across stakeholders
📌 Key KPIs
Total Premium Collected
Average Stakeholder Age
Total Value Created for Equity-based AUM
Highest Value Created by an Insurer
🔎 Interactive Features
City and stakeholder filters
Policy tenure range slider
Date range filter
Gender filter
Interactive charts with cross-filtering
Dynamic KPIs and tooltips
🛠️ Tools & Technologies
Tableau
Data Visualization
Business Intelligence
Interactive Dashboarding
💡 Business Value
The dashboard enables stakeholders to quickly identify premium trends, profitability patterns, insurer performance, and asset distribution, supporting more informed business decisions.
📄 Export & Access
The dashboard supports PDF export of visible KPIs, charts, and filters, along with role-based data visibility for different stakeholders.
